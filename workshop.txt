version=1
title=Chop Tree XP
description=[h1]Chop Tree XP[/h1]
description=In vanilla Build 42, the right-click [b]Chop Tree[/b] action gives no Strength XP (only hitting a tree manually does). This mod grants XP on [b]every hit[/b] of the automatic Chop Tree action.
description=
description=[h2]XP per hit[/h2]
description=[list]
description=[*][b]Strength 4.8 / Fitness 3.2[/b] - the same as one burpee rep (vanilla Fitness code). Proportional to the number of hits.
description=[*][b]Axe[/b] - proportional to the tree health removed by the hit, so every axe gives the same Axe XP per tree (Fire Axe: ~3 per hit).
description=[/list]
description=Values are before server XP multipliers. Only axe-category weapons give Axe XP.
description=
description=[h2]Multiplayer[/h2]
description=XP is granted where vanilla handles the chop hit (the server in MP, the local game in SP), so it is granted exactly once per hit and synced to the client. It does not stack with manual tree hits (OnWeaponHitTree).
description=
description=[h2]Sandbox options[/h2]
description=[list]
description=[*]Strength XP on/off, multiplier (default 1.0)
description=[*]Axe XP on/off, multiplier (default 1.0)
description=[*]Fitness XP on/off
description=[/list]
description=
description=[h2]Compatibility[/h2]
description=Wraps ISChopTreeAction.animEvent without replacing vanilla files. Safe to add to existing saves. Do not use together with other chop-tree XP mods (XP would stack).
description=
description=[h2]한국어[/h2]
description=우클릭 "나무 베기"(자동 벌목)로 나무를 칠 때마다 근력·체력·도끼 경험치를 지급합니다. 근력·체력은 버피 1회와 같은 양(4.8 / 3.2), 도끼는 깎은 나무 체력에 비례합니다(도끼 종류와 관계없이 그루당 동일). 멀티에서는 서버가 1회만 지급합니다. 샌드박스 옵션으로 켜기/끄기와 배율을 조정할 수 있습니다.
